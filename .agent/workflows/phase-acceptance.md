# Phase Acceptance Workflow
1. Evaluate every defined Gate (A through L for Phase 0) with concrete evidence.
2. Classify each item strictly as: Implemented and verified, Implemented but not verified, Designed only, Deferred, or Blocked.
3. Determine overall status: `PASS`, `CONDITIONAL PASS`, `FAIL`, or `BLOCKED`.
4. Never mark `PASS` if critical security, clinical safety, architectural, or environment blockers remain unresolved.
